01 / Build your clip list

Add videos, then add up to 8 time ranges for each video. Times accept seconds or HH:MM:SS.

How export works: YouTube links are used for reference and preview only. To create a downloadable video, attach the matching video file that you own or have permission to use. This static GitHub Pages version does not download videos from YouTube.

The preview plays the attached local clips in order when files are provided. Without a local file, use “Open YouTube preview” on the clip card.
